## Enoncé 

Ecrire le fichier de projet de notre salle et la construire. Retourner le fichier projet et la sortie de build

## Resolution

Il existe deux façon de disposer des informations du fichier de projet


1. Fichier de Projet `Salle2\Salle2.jenga` (fichié demandé par l'exercice)

    ```python

    #!/usr/bin/env python3
    # -*- coding: utf-8 -*-

    # Salle2 - Jenga Project (inclus dans le workspace via include())

    from Jenga import *

    with project("Salle2"):
        consoleapp()
        language("C++")
        cppdialect("C++17")
        location(".")
        files(["src/**.cpp", "include/**.hpp"])

    ```


2. Config du ficher de projet via le fichier Workspace `Salle.jenga`



    ```python
    #!/usr/bin/env python3
    # -*- coding: utf-8 -*-

    # Salle – Jenga Workspace
    # Generated by `jenga workspace` on 2026-09-24 03:31:19

    from Jenga import *

    with workspace("Salle"):
        configurations(['Debug', 'Release'])
        targetoses([TargetOS.WINDOWS])
        targetarchs([TargetArch.X86_64])
        
        # Default toolchain (auto-detected)
        # usetoolchain("host-gcc")
        
        # Uncomment to use Unitest testing framework
        # with unitest() as u:
        #     u.Precompiled()
        
        # Add your projects here
        # with project("MyApp"):
        #     consoleapp()
        #     language("C++")
        #     files(["src/**.cpp"])

        # Project: Salle
        with project("Salle"):
            consoleapp()
            language("C++")
            cppdialect("C++17")
            location("Salle")
            files(["src/**.cpp", "include/**.hpp"])

    ```
