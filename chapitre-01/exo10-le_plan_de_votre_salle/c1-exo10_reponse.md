## Énoncé

Dessiner la salle qui sera construite tout au long du livre. Placer la porte, les fenêtres, une table et ce qui sera posé dessus. Donner les dimensions en mètres.

## Plan (vue de dessus, salle carrée de 4 m × 4 m)

```
 ┌───────────────────────────────┐  ← mur nord
 │            fenêtre            │
 │           (1,2 × 1)           │
 │                               │
 │                    ┌────────┐ │
 │                    │ table  │ │
 │                    │0,8×1,2 │ │
 │                    │(h 0,8) │ │
 │                    └────────┘ │
 │                               │
 │                               │
 └──────┬────────────────────────┘
        │ porte (2 × 0,9)
        ↓
```

## Dimensions

| Élément | Dimensions |
|---|---|
| Salle | 4 m × 4 m, plafond 2,5 m |
| Porte | 2 m de haut, 0,9 m de large, mur sud |
| Fenêtre | 1,2 m × 1 m, mur nord |
| Table | 1,2 m × 0,8 m, hauteur 0,8 m |
| Objet sur la table | une tasse, 8 cm de haut |
