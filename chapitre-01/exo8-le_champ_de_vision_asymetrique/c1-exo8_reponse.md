## Enoncé

Chercher les quatre angles du champ de vision d'un casque du commerce, pour l'œil gauche, avec source. Dire ce qui se passerait avec un champ symétrique de même surface.

## Valeurs trouvées

Casque : **Valve Index**, œil gauche, angles bruts (avant recentrage) :

| Direction | Angle |
|---|---|
| Gauche | −49,00° |
| Droite | 47,98° |
| Bas | −54,63° |
| Haut | 54,73° |

Source : *HMD Geometry Database* (risa2000.github.io), extraction du runtime OpenVR 1.7.12.

## Observation

L'angle vers la gauche (−49°) est plus grand que vers la droite (47,98°) : pour l'œil gauche, le champ s'étend davantage vers l'extérieur du visage que vers le nez.

## Avec un champ symétrique de même surface

Un champ symétrique centré forcerait les deux moitiés à un angle identique. Pour garder la même ouverture totale, il faudrait soit rogner le côté extérieur, soit étendre le côté intérieur au-delà de ce que le nez laisse physiquement voir.
