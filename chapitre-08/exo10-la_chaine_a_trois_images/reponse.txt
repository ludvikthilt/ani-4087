Le cycle 0, 1, 2 se lit directement : une image revient toutes les trois trames.

Le minimum d'images : Une image repeinte revient toutes les n trames, et le compositeur la garde L trames. Il y a conflit des que n <= L, et aucun conflit des que n > L : le minimum est donc L + 1 images. Les conflits le montrent : n = 1, L = 1 donne 5 conflits et n = 2, L = 1 en donne 0 ; n = 2, L = 2 donne 4 conflits et n = 3, L = 2 en donne 0. Avec L = 0, une seule image suffit : n = 1, L = 0 donne 0 conflit.

Sur le simulateur : Le compositeur du simulateur lit apres le rendu, donc L y vaut 0 et une seule image suffit deja. Le cycle de trois images n'y evite aucun conflit et n'apporte rien a ce que l'on voit. Ce qu'il apporte est ailleurs : il fait tourner l'index, donc il oblige le code a respecter la discipline comme sur un vrai casque, ou une seule image cacherait une mauvaise lecture de l'index. Je n'ai pas mesure de gain de vitesse : ma mesure n'a tourne qu'avec trois images, sans comparaison avec une seule.
